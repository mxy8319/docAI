# DocAI - 个人智能文档知识库

> Next.js 14 + LLM + RAG 全栈 AI 应用
> 一站式文档解析、问答、摘要、知识库管理平台

---

## 🎯 产品定位

个人智能文档知识库，让非结构化数据变成可检索、可问答的知识资产。

### 一句话价值

> 上传任何文档 → AI 帮你读懂、总结、检索、问答、分析。

---

## 📋 产品需求文档 v1.0

### 1. 核心技术架构

#### 1.1 RAG 完整技术流程

```
用户上传文档
    ↓
1. 📄 文档解析层
   ├─ PDF / TXT / MD 解析
   ├─ 与页码绑定
   └─ 输出：纯文本 + 元数据（页码、坐标）
    ↓
2. ✂️ 智能分块层
   ├─ 语义分块（不切断句子）
   ├─ 每个 chunk ~512 tokens
   └─ 保留 chunk 和原文档的映射关系
    ↓
3. 🔢 向量化层
   ├─ 模型：OpenAI text-embedding-3-small
   └─ 每个 chunk → 1536 维向量
    ↓
4. 💾 存储层
   ├─ 向量库：PGVector (PostgreSQL 插件)
   ├─ 业务库：PostgreSQL
   │  ├─ 用户数据、权限、MVP
   │  ├─ 文档元数据
   │  └─ Chunk 来源信息（页码、坐标）
   └─ 文件存储：Supabase Storage
    ↓
5. 🔍 检索层
   ├─ 用户问题转成向量
   ├─ 向量相似度检索 Top 20
   └─ BM25 全文检索 Top 20
    ↓
6. ✨ 生成层
   ├─ 相关 Chunk 拼装成 Prompt
   ├─ LLM 生成回答
   ├─ 附加引用来源
   └─ 引用校验（Verify）
    ↓
用户拿到：答案 + 可溯源的原文引用
```

### 3. 进阶功能（Phase 2）

#### 3.1 大文档处理 P1

| 问题                | 技术方案                       |
| ------------------- | ------------------------------ |
| 1000 页以上内存溢出 | 异步任务队列 + Worker 分批处理 |
| 内存控制            | 流式解析 + 及时释放            |
| 任务状态            | 后台处理 + 进度通知            |
| 排队机制            | 超过 2 个大文档自动排队        |

#### 3.2 检索优化 P1

| 优化点           | 方案                           |
| ---------------- | ------------------------------ |
| 召回率提升       | 混合检索：向量 + BM25 双路召回 |
| 准确率提升       | Rerank 重排序 Top 20 → Top 5   |
| 检索准确率 > 90% | 多路召回 + 重排序              |

#### 3.3 智能分块 P1

- 基于语义的智能分块
- 不切断句子和段落
- 重叠分块策略

---

### 4. 关键技术难点与解决方案

| 序号 | 问题           | 解决方案                         |
| ---- | -------------- | -------------------------------- |
| Q1   | 大文档内存溢出 | 异步队列 + 分批处理 + Worker     |
| Q2   | 智能语义分块   | 递归字符分割 + 语义边界检测      |
| Q3   | LLM 胡说八道   | Prompt 硬约束 + 引用反向校验     |
| Q4   | 引用不准确     | Chunk 与原文档页码、坐标精确绑定 |
| Q5   | 检索不相关     | 向量 + BM25 混合检索 + Rerank    |
